# SSD GTBuilder — Construction & Building Website

A multi-page construction and building website concept designed to present construction services, architecture, renovation work, completed projects, and company information through a responsive web interface.

## Live Demo

[View the live website](https://mkaceduet-hub.github.io/SSD_GTBuilder/)

## Project Overview

SSD GTBuilder is a front-end website project for a construction-focused brand. The homepage introduces building and renovation services, while the navigation connects visitors to project, service, company, news, team, and contact pages.

## Main Sections

- Construction-focused homepage and hero presentation
- Building, architecture, roof repair, and renovation service highlights
- Company introduction and service information
- Project and project-detail pages
- News and article pages
- Team and contact pages
- Additional shop, product, cart, and checkout demonstration pages

## Technologies & Libraries

- HTML5
- CSS3
- Bootstrap
- JavaScript
- jQuery-based interface plugins
- Font Awesome and icon fonts
- Owl Carousel, Nivo Slider, and Fancybox

## Project Structure

- `index.html` — main homepage
- `index2.html` — alternate homepage
- `about.html` — company information
- `project.html` and `project-detail.html` — project presentation
- `service.html` and `service-detail.html` — service information
- `news.html` and related pages — news content
- `team.html` and related pages — team presentation
- `contact.html` — contact page
- `css/`, `js/`, `img/`, and `lib/` — stylesheets, scripts, images, and supporting libraries

Keep the supporting folders in their original locations when downloading or deploying the project.

## Run Locally

1. Download or clone this repository.
2. Open the project folder in Sublime Text or your preferred code editor.
3. Open `index.html` in a modern web browser.

No package installation is required for a basic local preview.

## Important Notes

This is a front-end portfolio demonstration. Forms, search, shopping cart, checkout, and other interactive elements may require backend services to work as production features. Review all sample text, contact details, images, and third-party library licenses before using the project for a real business.
